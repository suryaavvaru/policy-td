# Release status

Policy-TD v0.1.0 is a manuscript-stage public research artifact.

The repository contains the stable package surface, documentation, tests, curated frozen-result tables, benchmark reports, provenance manifests, and release verification scripts. It intentionally excludes raw provider transcripts, local research workbench state, and large checkpoints.

A public-clean frozen runtime archive is intended to be attached to the manuscript/preprint release. Until that archive (and any required checkpoint bundle) is attached, the repository should be described as supporting **artifact inspection and result traceability**, not complete from-scratch reproduction.

## Manuscript snapshot

The current manuscript and supplementary information are versioned under `paper/`.
The public repository should be interpreted as supporting artifact inspection,
result traceability, and verification of the released evidence. It does not
publish the complete internal experimental workbench.
