# Frozen release notes

This release freezes the Policy-TD runtime-control evidence used for the current manuscript.

## Included in git

- Modular Policy-TD package foundation.
- Teacher-label schema and validation utilities.
- Runtime action vocabulary.
- Paired helped/harmed metrics.
- Curated frozen result tables.
- Internal global heldout benchmark report.
- External-style benchmark report.
- Real public external benchmark report.
- Result inspection CLI.
- Repository release audit script.

## Excluded from git

- Raw local workbench logs.
- Large generated runtime directories.
- Local process files.
- Legacy prototype scripts.
- Provider-switching experiments.
- Checkpoints or trained guide bundles unless released separately.

## Checkpoint note

If full trained-guide execution is required by reviewers or researchers, the trained guide/checkpoint should be staged as a separate checkpoint bundle rather than mixed into the curated result archive.
